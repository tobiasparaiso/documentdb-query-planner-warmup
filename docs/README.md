# Project Notes and Prompts

This directory contains historical prompts and workflow notes used while building the project. These files are useful for understanding project intent, but they are not runtime documentation and are not required to run the toolkit.

For operational usage, start with the root `README.md`, then use:

- `query-warmup/README.md` for the Performance Insights extraction and candidate generation workflow
- `sample-data/README.md` for optional demo data and workload generation
- `scripts/README.md` for the optional DocumentDB MCP launcher

## Files

- `prompt-1-build-toolkit.md`: original request to build the extraction, filtering, and candidate generation scripts
- `prompt-2-warm-up-skill.md`: request to create the repo-local Codex warm-up skill
- `prompt-3-execute-skill.md`: example instruction for running the warm-up workflow
- `prompt-5-docdb-mcp.md`: original MCP server planning request
